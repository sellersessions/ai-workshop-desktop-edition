# Module 000: Install Claude Desktop

Getting set up takes about ten minutes. There is nothing to configure and nothing to type into a command line.

## What you need first

| Requirement | Detail |
|---|---|
| A computer | Mac (macOS 13 or later) or Windows (Windows 10 or later) |
| A paid Claude plan | Pro or Max. The Code tab is not available on the free plan |
| Ten minutes | Downloading and signing in is most of it |

Nothing else. No code editor, no developer account, nothing to install alongside it.

## Step 1: Download and sign in

Go to **claude.ai/download** and install Claude Desktop the normal way for your machine. Open it and sign in with the account your paid plan sits on.

If you already use Claude in a browser, this is the same account and the same conversations.

## Step 2: Open the Code tab

Claude Desktop has several tabs down the side. The one this course uses is called **Code**.

Chat is for talking. Code is for working on a folder of files. Everything in Modules 1 to 5 happens in the Code tab.

## Step 3: Make your project folder

Create one folder for your Claude work. Put it somewhere you will find it again, such as your Documents folder, and call it:

`Claude-projects`

Leave it empty. Claude fills it as you go.

## Step 4: Point Claude at that folder

In the Code tab, look along the top of the window. Next to the name of your session there is a small **folder icon**. Click it, choose **Change directory**, and pick the `Claude-projects` folder you just made.

That is the single step people get wrong, so it is worth being precise about two things:

- The search box in the Files panel on the right is **not** the folder picker. It only searches inside the folder you are already in.
- The name of your current folder shows next to the session title. Glance at it whenever you start work, because a new session opens in whichever folder you used last.

## Step 5: See a decision board

The last thing to do is meet the way Claude asks you questions in this course.

Drag `MODULE-000-GIVE-TO-CLAUDE.md` from this folder into the chat, type the line below, and press send:

> Follow the instructions in this file, one step at a time.

Claude will confirm your folder, create a small file so you can see it working, then ask you a question as a set of clickable cards. Click one. That is the pattern for the whole course.

## How every module works from here

1. Read the module's `READ.pdf`.
2. Drag the module's `GIVE-TO-CLAUDE.md` into the chat with that same line.
3. Click your answers.
4. Check the result before moving on.

Five modules, same four steps. Module 1 is next.
