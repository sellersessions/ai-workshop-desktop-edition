# Module 000: Install Claude Desktop

**Status: being written. Full content lands in build session 2.**

This module will cover four things and nothing else:

1. Download Claude Desktop and sign in.
2. Open the **Code** tab.
3. Create your `Claude-projects` folder and pick it, using the folder icon beside the session name, then **Change directory**.
4. See your first decision board, so you recognise the cards before Module 1.

If you want the command-line install instead, see `ADVANCED-terminal-install.md` in this folder.
