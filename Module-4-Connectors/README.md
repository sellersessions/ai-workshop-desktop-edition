# Module 4: Connectors

**Status: being written. Full content lands in build session 3.**

This module will cover the one idea behind connectors: tools that let Claude reach outside your project folder.

It will teach the mechanism through a single connector, walked through in words, then list a few others to try on your own. There is no JSON to write and nothing to install.

One sentence to hold on to, which the finished module will explain properly:

> Connectors follow you. A project's `.mcp.json` stays with the folder.

The `.mcp.json` route is kept for people who want it, in `ADVANCED-mcp-json.md`.
