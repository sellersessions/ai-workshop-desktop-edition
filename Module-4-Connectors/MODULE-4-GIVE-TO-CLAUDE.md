# Module 4: Connectors

**Follow the instructions in this file, one step at a time.**

**Claude: ask each question below with your multiple-choice tool whenever there are options, so the learner can click an answer rather than type one.**

---

You are teaching someone what a connector is by having them use one. Keep it short and plain. Never ask them to install anything, edit a settings file, or open a command line. If something is not working, the answer is almost always "start a new session and ask me again", not a fix on their machine.

## Step 1: Find out what is already connected

Tell the learner, in plain words, which tools you can currently reach. Group them so it is readable: things inside their folder, and services outside it.

Then ask: **do you already have a connector switched on, such as Google Drive, Gmail or Notion?**

Options: yes, I can see one in your list / no, nothing outside my folder / I am not sure.

If they have none, walk them through adding one: claude.ai in the browser, Settings, Connectors, pick one, approve the access, then come back and start a new session in the Code tab. Wait for them. When they return, check again and tell them what changed.

## Step 2: Learn the rule

Explain, in two sentences, that a connector belongs to their account and follows them into every folder, whereas the `CLAUDE.md`, commands and agents they built in Modules 1 to 3 belong to this folder and stay behind.

Then ask: **if you start a project in a different folder tomorrow, which of these comes with you?**

Options: the connector / the slash commands / both / neither.

The answer is the connector. If they pick something else, correct it warmly in one sentence and move on. Do not labour it.

## Step 3: One question about their setup

Ask: **which folder or mailbox should we use for the exercise?**

Let them answer in their own words. Use whatever they name.

## Step 4: The exercise

Do these two things, in order, and show the result each time.

1. List what is in the place they named. Keep the list short.
2. Take one item from it, read it, and write a short summary into a new file in their project folder.

Then say what just happened in one sentence: you reached outside their folder, brought something back, and saved it inside their project. That is the whole point of a connector.

## Step 5: Close

Tell them, briefly:

- They can add more connectors the same way, one at a time, when they have a use for one.
- Module 5 is next, and it is about agents: specialists that run longer pieces of work.

Then stop. Do not start Module 5.
