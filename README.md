# AI Workshop 2.0 -- Desktop Edition

**A GBP 1,000 course. Free. Self-drive. No support.**

This is the full Claude curriculum from the Seller Sessions Live AI Workshop. It takes you from zero to a working AI-powered project setup in one sitting.

There is no instructor. There is no helpdesk. You hand Claude one file from each module, click your answers, and Claude builds everything for you.

You will not type a single command anywhere in this course.

---

## The two files in every module

Every module folder holds exactly two files. The file name tells you what to do with it.

| File | Who it is for | What you do |
|---|---|---|
| `MODULE-N-READ.pdf` | You | Read it first. It explains what you are about to build and why |
| `MODULE-N-GIVE-TO-CLAUDE.md` | Claude | Drag it into the chat. Claude reads it and does the work |

You never have to open the `.md` file yourself. Its whole job is to be handed over.

---

## How every module works

The same five steps every time, so it becomes muscle memory:

1. Open Claude Desktop and click the **Code** tab.
2. Pick your `Claude-projects` folder. First time only, it remembers after that.
3. Read the module's `READ.pdf`.
4. Drag the module's `GIVE-TO-CLAUDE.md` file into the chat, add the line printed at the top of this page, and press send.
5. Click your answers on the cards Claude shows you. Check the result before moving on.

**The line you send with every GIVE file:**

> Follow the instructions in this file, one step at a time.

Work through these in order. Each module builds on the one before it.

```

    |
Module-1    CLAUDE.md                 Your project config file: Claude's standing instructions
    |

    |
Module-3    Slash Commands            Custom commands that automate repetitive tasks

    |
Module-5    Agents                    Specialists that run multi-step work for you
```

Module-00 sits at the end on purpose. Claude Desktop opens and edits your files itself, so you do not need a code editor to finish this course. Module-00 is there for the day you want one.

## Tips

- **Go in order.** Module-1 needs Module-000 done first. Module-5 needs everything before it.
- **Read the PDF first.** Every module explains *why* before showing *how*.
- **Trust Claude.** The GIVE files are tested. If Claude asks a question, answer it. If something breaks, paste the error back to Claude.
- **Take breaks.** This is 4 to 6 hours of material. Two modules per sitting is plenty.
- **Chat getting long?** Start a new session. Your `CLAUDE.md` and Master Log carry across, which is the whole point of Modules 1 and 2.
- **English not your first language?** Ask Claude to translate any module into your language before you start. The GIVE files work in any language.
