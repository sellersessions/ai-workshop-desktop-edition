# Content Research Writer Skill

Your writing partner. Give it a topic, a transcript, or some research -- it helps you turn raw material into polished content.

## When to Use

- Writing blog posts, articles, or newsletters
- Turning a YouTube transcript into an article or summary
- Creating content from existing research
- Drafting product descriptions or case studies
- Any writing where you want structure and feedback

## How It Works

### Step 1: Understand the Project

Ask these questions (skip any the user has already answered):

1. **What are you writing?** (blog post, article, newsletter, summary)
2. **Who's the audience?** (Amazon sellers, general public, technical readers)
3. **What's the source material?** (transcript, research notes, your own ideas)
4. **What tone?** (conversational, professional, educational)

### Step 2: Check for Source Material

Look in the current folder for:
- Research briefs (`.md` files) -- from the Web Researcher skill
- Any other `.md` files with notes or research
- Files the user mentions

If source material exists, read it and extract key points before outlining.

### Step 3: Collaborative Outline

Create a structured outline with:
- Hook / opening (why should the reader care?)
- 3-5 main sections with key points
- Conclusion / call to action

Show the outline and ask: "Does this structure work? Want to adjust anything?"

### Step 4: Write Section by Section

Draft each section one at a time:
1. Write the section
2. Show it to the user
3. Get feedback or approval
4. Move to the next section

### Step 5: Polish

Once all sections are drafted:
- Review for flow between sections
- Check consistency of tone
- Tighten any wordy passages
- Add a compelling title if not done already

## Rules

- **Preserve the user's voice** -- make their writing better, not different
- **UK English** spelling throughout
- **Short paragraphs** -- 3-4 lines max, scannable
- **No filler** -- every sentence should earn its place
- **Show don't lecture** -- suggest options, don't dictate
- **Save the output** -- write the final draft to a `.md` file in the project folder

## The Research Chain

This skill works perfectly after the Web Researcher skill:

1. User runs `/web-researcher` to gather material on a topic
2. User says "write an article from that research" or "turn this into a blog post"
3. This skill reads the research brief, extracts the key ideas, and helps draft content

This is the power of skills working together.
